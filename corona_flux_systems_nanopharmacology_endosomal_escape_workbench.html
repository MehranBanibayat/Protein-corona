How This Project Works & How to Showcase It on Your GitHub

Most computational biology repos ignore formulation chemistry, and most drug delivery tools use static regression tables. By coupling De Gennes polymer physics, competitive Vroman ODE kinetics, and endosomal protonation thermodynamics in a zero-dependency interactive web simulator, your GitHub stands out to both wet-lab formulation teams and computational systems biologists.

Module 01 // Polymer Brush Physics

De Gennes Mushroom-to-Brush Transition

From PEG molar fraction fPEG and mean lipid headgroup area (AL ≈ 0.65 nm²), we calculate inter-chain grafting distance D = √(AL / fPEG) and compare it against the Flory radius RF = a·N3/5 (3.43 nm for PEG2000). As RF/D > 1.0, chains extend into a steric brush that exponentially dampens protein association rate constants kon,i.

Module 02 // Competitive ODE Solver

4th-Order Runge-Kutta Vroman Kinetics

Rather than hardcoding static corona percentages, the function solveVromanRK4() integrates coupled differential equations dθi/dt over 3,600 seconds. High-abundance Albumin (600 μM) dominates early milliseconds, while PEG acyl desorption (kshed for C14 vs. C18) opens binding sites for high-affinity ApoE or C3b/IgG opsonins.

Module 03 // Endosomal Escape Window

Henderson-Hasselbalch & HII Phase Flux

As the endosome acidifies from pH 7.4 → 4.7, ionizable lipids protonate via α = 1 / (1 + 10pH - pKa). Escape requires ion-pairing with anionic endosomal BMP lipids inside the pH 6.2–5.4 window before lysosomal hydrolases degrade the payload at pH < 5.0.

How to Extend This with Your Own Wet-Lab Data

  • 1. Add Your Custom Ionizable Lipids or Polymers: Edit the PRESETS object in the script to include your own synthesized lipidoids, PLGA-b-PEG copolymers, or exosome surface formulations with measured DLS diameter and TNS-assay apparent pKa.
  • 2. Calibrate kon & koff from LC-MS/MS Proteomics: Replace the baseline affinity constants in solveVromanRK4() with experimental equilibrium dissociation constants (KD) from BLI/SPR or nano-LC-MS/MS corona time-courses.
  • 3. Deploy Instantly on GitHub Pages: Push index.html to a new repository, enable Settings → Pages → Deploy from main branch, and put the live interactive link at the top of your CV and manuscripts.
